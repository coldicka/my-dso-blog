*Bestehende Anwendung · Weiterbildungsprojekt*

## Aufgabe

Einen bestehenden Django-Shop um Produkt-Tags erweitern.

## Mein Beitrag

Ich ergänzte Tag-Modell, Admin-Verwaltung, verlinkte Tags und eine gefilterte Produktansicht und passte das Bewertungsformular an.

## Ergebnis

Tag-Verwaltung und Produktzuordnung sind mit der Shop-Oberfläche verbunden.

## Technische Entscheidungen und Umfang

Shop, Anmeldung und Bewertungssystem stammen aus der Kursvorlage. Darauf baut meine Erweiterung auf. Die optionale Many-to-many-Beziehung erlaubt mehrere Tags je Produkt, lässt aber auch Produkte ohne Tags zu.
