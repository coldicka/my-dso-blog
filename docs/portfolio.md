## Project contribution

*Personal project · Based on Docusaurus*

**Task:** Present my experience and projects in an accessible, bilingual website.

**My contribution:** I develop React components, responsive SCSS layouts and German/English content, with a GitHub Pages deployment workflow.

**Result:** A bilingual portfolio connects my professional background with documented project work.

### Technical choices and scope

Docusaurus provides the site and documentation framework. My work focuses on the portfolio components, responsive presentation, translations and deployment configuration.

[Project source code](https://github.com/coldicka/my-dso-blog)

## Technology

React components, TypeScript, SCSS modules and Docusaurus translations form the website. The GitHub Actions configuration builds the site and publishes it to GitHub Pages.
